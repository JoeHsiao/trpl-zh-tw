# 前言

[foreword.md](https://github.com/rust-lang/book/blob/112ceaedfa51d79327e33057c9806d0ea370004a/src/foreword.md)

Rust 程式設計語言在短短几年內走過了很長的路，從由一小群尚處起步階段的愛好者社群建立並孵化，到成為世界上最受喜愛、需求最旺盛的程式語言之一。回望過去，Rust 的強大與潛力讓它引人注目，並在系統程式設計中站穩腳跟，這幾乎是不可避免的。並非理所當然的，則是滲透於開源社群之中的全球範圍內興趣與創新的增長，並催化了產業內的大規模採用。

此時此刻，很容易指出 Rust 所必須提供的一系列出色特性，來解釋它在關注度與採用率上的激增。誰會不想要記憶體安全，*並且* 高效能，*並且* 友好的編譯器，*並且* 出色的工具鏈，以及其他眾多優秀特性呢？你今天看到的 Rust，將系統程式設計領域多年的研究成果與一個充滿活力、富有熱情的社群所積累的實踐智慧融為一體。這門語言被有目的地設計，並被精心打磨，為開發者提供了一種更容易編寫安全、快速且可靠的程式碼的工具。

不過，使 Rust 真正與眾不同的是它根植於賦能你——也就是使用者——去實現你的目標。這是一門希望你成功的語言，而賦能這一原則貫穿於構建、維護並倡導這門語言的社群核心。自本書上一版以來，Rust 進一步發展為一門真正全球化且值得信賴的語言。Rust 專案（Rust Project）如今得到了 Rust 基金會（Rust Foundation）的強有力支援，該基金會也在關鍵倡議上持續投入，以確保 Rust 安全、穩定且可持續。

這一版的《Rust 程式設計語言》是一次全面更新，反映了這門語言多年來的演進並提供了有價值的新資訊。但它不僅僅是一份關於語法和庫的指南——更是一份邀請，歡迎你加入一個重視質量、效能與深思熟慮設計的社群。無論你是經驗豐富的開發者想第一次探索 Rust，還是資深的 Rustacean 想進一步打磨你的技能，這一版都能為每個人提供值得收穫的內容。

Rust 的歷程是一段協作、學習與迭代的旅程。語言及其生態系統的成長直接反映了其背後充滿活力、豐富多元的社群。成千上萬開發者的貢獻——從核心語言設計者到隨手貢獻的參與者——共同造就了 Rust 這一獨特且強大的工具。拿起本書，你不僅是在學習一門新的程式語言——你是在加入一場讓軟體更好、更安全、並且更令人愉快的運動。

歡迎來到 Rust 社群！

- Bec Rumbul，Rust 基金會執行董事
