歡迎閱讀《Rust 程式設計語言》，這是一本關於 Rust 的入門書籍。Rust 程式語言能幫助你編寫更快、更可靠的軟體。在程式語言設計中，高層工程學與底層控制往往彼此衝突；而 Rust 則試圖挑戰這一矛盾。通過平衡強大的技術能力與優秀的開發者體驗，Rust 為你提供了控制底層細節（如記憶體使用）的選項，而無需承受傳統上與此類控制相關的所有繁瑣負擔。

## Rust 適合哪些人

Rust 因多種原因適合許多人。讓我們看看幾個最重要的群體。

### 開發者團隊

Rust 已被證明是一個適合擁有不同系統程式設計知識水平的大型開發團隊協作的高效工具。底層程式碼容易出現各種微妙的錯誤，而在大多數其他語言中，這些錯誤往往只能通過大量測試以及經驗豐富的開發者進行細緻的程式碼審查來發現。在 Rust 中，編譯器充當了守門人的角色，會拒絕編譯包含這類隱蔽錯誤的程式碼，其中也包括併發錯誤。通過與編譯器協作，團隊可以將時間集中在程式邏輯上，而不是到處追查 bug。

Rust 也為系統程式設計世界帶來了現代化的開發工具：

- Cargo 是內建的依賴管理器和構建工具，它能輕鬆增加、編譯和管理依賴，並使依賴在 Rust 生態系統中保持一致。
- Rustfmt 格式化工具確保開發者遵循一致的程式碼風格。
- Rust Language Server 為整合開發環境（IDE）提供程式碼補全和內聯錯誤資訊功能。

通過使用 Rust 生態系統中豐富的工具，開發者在編寫系統級程式碼時可以更加高效。

### 學生

Rust 適合學生，也適合那些有興趣學習系統概念的人。許多人通過 Rust 學習了作業系統開發等主題。社群非常歡迎學生提問，也樂於回答。通過這本書以及其他類似內容的努力，Rust 團隊希望讓系統概念對更多人來說更容易理解，尤其是那些程式設計新手。

### 公司

數百家大大小小的公司在生產環境中使用 Rust 完成各種任務，包括命令列工具、Web 服務、DevOps 工具、嵌入式裝置、音影片分析與轉碼、加密貨幣、生物資訊學、搜尋引擎、物聯網（IoT）應用、機器學習，甚至是 Firefox 瀏覽器的重要組成部分。

### 開源開發者

Rust 適合那些希望構建 Rust 程式語言、社群、開發工具和庫的開發者。我們非常歡迎你為 Rust 語言作出貢獻。

### 重視速度和穩定性的開發者

Rust 適合那些看重速度與穩定性的人。這裡所說的速度，既指 Rust 程式碼執行得有多快，也指 Rust 讓你編寫程式的速度有多快。Rust 編譯器的各項檢查，能夠在新增新功能和重構時保障穩定性。這與那些缺少這些檢查的語言中脆弱的遺留程式碼形成鮮明對比，因為開發者往往害怕修改那樣的程式碼。通過追求零成本抽象（zero-cost abstractions）這種目標，也就是讓高階特性編譯成底層程式碼後依然和手寫程式碼一樣快，Rust 致力於讓安全的程式碼也同樣快速。

這裡提到的只是幾個較大的受益群體，Rust 語言也希望能支援更多其他使用者。總的來說，Rust 最大的抱負是消除程式設計師數十年來一直接受的那些取捨，讓安全與生產力、速度與易用性**可以兼得**。試試看 Rust，看看它的選擇是否適合你。

## 本書適合哪些人

本書假設你已經寫過另一種程式語言的程式碼，但不限定具體是哪一種。我們努力讓擁有各種程式設計背景的人都能讀懂本書。本書不會花太多篇幅討論程式設計**本身**是什麼，也不會詳細講如何建立程式設計思維。如果你完全沒有程式設計經驗，那麼先讀一本專門介紹程式設計的入門書會更合適。

## 如何閱讀本書

本書大體上假設你按從頭到尾的順序閱讀。後面的章節建立在前面章節概念的基礎上。前面的章節可能不會深入介紹部分主題，而是留待後續章節重新討論。

本書分為兩類章節：概念章節和專案章節。在概念章節中，我們學習 Rust 的某個方面。在專案章節中，我們會一起構建小程式，將目前學到的知識應用起來。第二、十二和二十一章是專案章節；其餘都是概念章節。

第一章介紹如何安裝 Rust，如何編寫一個 “Hello, world!” 程式，以及如何使用 Rust 的包管理器和構建工具 Cargo。第二章則通過構建一個猜數字遊戲，帶你動手編寫 Rust 程式。這裡我們會在較高層次上介紹一些概念，而後續章節將提供更多細節。如果你想立刻動手實踐，第二章就是最適合開始的地方。第三章介紹 Rust 中那些與其他程式語言相似的特性，第四章會學習 Rust 的所有權系統。如果你是一個特別細緻的學習者，喜歡在進入下一環節之前學習每一個細節，你可能會想跳過第二章，直接閱讀第三章；之後等你想通過專案運用學到的細節時，再回到第二章。

第五章討論結構體（struct）和方法，第六章介紹列舉（enum）、`match` 表示式，以及 `if let` 和 `let...else` 控制流結構。在 Rust 中，建立自定義型別需要用到結構體和列舉。

第七章介紹 Rust 的模組（module）系統，以及用於組織程式碼及其公開 API（應用程式介面）的私有性規則。第八章討論標準庫提供的一些常見集合資料結構，例如 vector（動態陣列）、字串和 hash map（散列表、雜湊表）。第九章探索 Rust 的錯誤處理理念與技術。

第十章深入介紹泛型（generic）、Trait 和生命週期（lifetime），這些功能讓你能夠定義適用於多種型別的程式碼。第十一章全面講述了測試，因為就算 Rust 有安全保證，也需要測試確保程式邏輯正確。第十二章中將會構建我們自己的 `grep` 命令列工具的功能子集實現，用於在檔案中搜索文本。為此會用到之前章節討論的很多概念。

第十三章探索閉包（closure）和迭代器（iterator），它們是來自函數語言程式設計語言的 Rust 特性。第十四章會更深入地探討 Cargo，並介紹與他人共享庫的最佳實踐。第十五章討論標準庫提供的智慧指標以及使其發揮作用的 trait。

第十六章將引導我們瞭解不同的併發程式設計模型，並探討 Rust 如何幫助你無畏地進行多執行緒程式設計。第十七章將在此基礎上進一步探索 Rust 的 async 和 await 語法，以及任務、future 和 stream，還有它們所支援的輕量級併發模型。

第十八章著眼於 Rust 風格與你可能比較熟悉的 OOP（物件導向程式設計）原則之間的比較。第十九章是一個關於模式與模式匹配的參考，它們是在 Rust 程式中表達思想的有力方式。第二十章則彙集了一系列你可能感興趣的高階主題，包括不安全 Rust（unsafe Rust）、宏（macro），以及更多關於生命週期、trait、型別、函式和閉包的內容。

第二十一章我們將會完成一個專案，實現一個底層多執行緒的 Web 服務端！

最後的附錄包含了一些關於該語言的實用資訊，其格式更像是參考資料。附錄 A 涵蓋了 Rust 的關鍵字，附錄 B 涵蓋了 Rust 的運算子和符號，附錄 C 涵蓋了標準庫提供的可派生 trait，附錄 D 涵蓋了一些有用的開發工具，而附錄 E 解釋了 Rust 版本。在附錄 F 中，你可以找到本書的翻譯版本，而在附錄 G 中，我們將討論 Rust 是如何製作的以及什麼是 nightly Rust。

閱讀本書沒有錯誤的方式：如果你想跳過前面的內容，儘管跳過！如果你遇到任何困惑，可能需要回到前面的章節。請採取對你最有效的方式進行閱讀。

學習 Rust 的一個重要部分，是學會如何閱讀編譯器顯示的錯誤資訊：它們會指引你寫出能執行的程式碼。為此，我們將提供許多無法編譯的示例，以及編譯器在每種情況下會顯示的錯誤資訊。請注意，如果你隨手輸入並執行某個示例，它可能無法編譯！請務必閱讀示例周圍的文字，確認你嘗試執行的示例是否本來就預期會報錯。Ferris 也會幫助你區分那些本就不是為了正常工作的程式碼：
