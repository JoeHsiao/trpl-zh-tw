# 泛型、Trait 和生命週期

[ch10-00-generics.md](https://github.com/rust-lang/book/blob/3986f214fd82427b4401adf4d7dc0911c917e1e8/src/ch10-00-generics.md)

每種程式語言都有一些工具，用來高效處理概念上的重複。在 Rust 中，這樣的工具之一就是**泛型**（*generics*）：它是具體型別或其他屬性的抽象佔位符。我們可以描述泛型的行為，或者它們與其他泛型之間的關係，而不需要在編譯和執行程式碼時就提前知道它們具體會被什麼替換。

函式可以像接收未知值那樣，接收某種泛型型別的引數，而不是像 `i32` 或 `String` 這樣的具體型別，從而讓同一段程式碼可以作用於多種具體值。事實上，我們已經在第六章見過 `Option<T>`，在第八章見過 `Vec<T>` 和 `HashMap<K, V>`，在第九章見過 `Result<T, E>`。本章將繼續探索如何使用泛型來定義我們自己的型別、函式和方法！

首先，我們會回顧如何透過提取函式來減少程式碼重複。然後，我們會使用同樣的技巧，把兩個只在引數型別上不同的函式變成一個泛型函式。我們也會解釋如何在結構體和列舉定義中使用泛型型別。

然後，你會學到如何使用 **trait** 以泛型的方式定義行為。你可以把 trait 和泛型型別組合起來，把某個泛型型別限制為只接受具有特定行為的型別，而不是任意型別。

最後，我們會討論 **生命週期**（*lifetimes*）：它是一類向編譯器提供“引用之間如何相互關聯”資訊的泛型。生命週期讓我們能夠向編譯器提供足夠的資訊，使它在更多場景下也能確認引用是有效的。

## 提取函式來減少重複

泛型允許我們使用一個可以代表多種型別的佔位符來替換特定型別，以此來減少程式碼冗餘。在深入瞭解泛型的語法之前，我們首先來看一種沒有使用泛型的減少冗餘的方法，即提取一個函式。在這個函式中，我們用一個可以代表多種值的佔位符來替換具體的值。接著我們使用相同的技術來提取一個泛型函式！透過學習如何識別並提取可以整合進一個函式的重複程式碼，你也會開始識別出可以使用泛型的重複程式碼。

`largest` 函式有一個名為 `list` 的引數，它表示任何傳給該函式的 `i32` 值切片。因此，當我們呼叫這個函式時，程式碼會執行在我們傳入的具體值上。

總的來說，我們把程式碼從示例 10-2 改成示例 10-3 時，經歷了下面這些步驟：

1. 找出重複程式碼。
2. 將重複程式碼提取到了一個函式中，並在函式簽名中指定了程式碼中的輸入和返回值。
3. 將重複程式碼的兩個例項，改為呼叫函式。

接下來，我們會用同樣的步驟藉助泛型來減少重複。就像函式體可以處理抽象的 `list`、而不是特定的值一樣，泛型也允許程式碼處理抽象型別。

例如，假設我們有兩個函式：一個用來找出 `i32` 切片中的最大項，另一個用來找出 `char` 切片中的最大項。我們該如何消除這種重複呢？繼續往下看。
