# 使用結構體組織相關聯的資料

[ch05-00-structs.md](https://github.com/rust-lang/book/blob/8a6130451b0817ead5c2522ce641dcb0f11a8571/src/ch05-00-structs.md)

**結構體**（*struct*），或者 *structure*，是一個自定義資料型別，允許你包裝和命名多個相關的值，從而形成一個有意義的組合。如果你熟悉一門面向物件語言，你會發現一個 struct 就像物件的資料屬性。在本章中，我們會比較元組和結構體的異同，在你已有知識的基礎上進一步探討，並演示在何種情況下結構體是組合資料的更好方式。

我們還將演示如何定義和例項化結構體，並討論如何定義關聯函式，特別是被稱為 *方法* 的那種關聯函式，以指定與結構體型別相關的行為。結構體和列舉（*enum*，會在第六章介紹）是為你的程式領域建立新型別的基礎構件，從而可以充分利用 Rust 的編譯時型別檢查。
