# 高階特性

[ch20-00-advanced-features.md](https://github.com/rust-lang/book/blob/57ff62db22b006e6b319e2e35c9364d932a8b4e5/src/ch20-00-advanced-features.md)

現在你已經學會了 Rust 程式語言中最常用的那些部分。在第二十一章再做一個專案之前，我們先來看語言中的一些方面：你可能偶爾會遇到它們，但未必會天天使用。你可以把這一章當作在遇到陌生內容時的參考。本章介紹的這些特性只會在非常特定的場景下派上用場。雖然你可能不會經常用到它們，但我們仍希望確保你瞭解 Rust 所提供的全部特性。

本章將涉及如下內容：

- 不安全 Rust：如何選擇退出 Rust 的某些保證，並負責手動維持這些保證
- 高階 trait：關聯型別、預設型別引數、完全限定語法、超 trait，以及與 trait 相關的 newtype 模式
- 高階型別：關於 newtype 模式的更多內容、類型別名、never 型別以及動態大小型別
- 高階函式和閉包：函式指標和返回閉包
- 宏：在編譯時定義“用來定義更多程式碼的程式碼”的方式

這是一組包羅永珍的 Rust 特性，總有一些內容會對你有用！讓我們開始吧！
