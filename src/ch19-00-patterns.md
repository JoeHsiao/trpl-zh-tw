# 模式與模式匹配

[ch19-00-patterns.md](https://github.com/rust-lang/book/blob/f8f5adae0982518b8b37a6b8cbfced399d12fc3a/src/ch19-00-patterns.md)

**模式**（*pattern*）是 Rust 中一種特殊的語法，用來匹配型別的結構，無論型別簡單還是複雜。將模式與 `match` 表示式及其他結構結合使用，可以讓你對程式的控制流有更多掌控。模式由以下內容中的某種組合構成：

- 字面值
- 解構後的陣列、列舉、結構體或元組
- 變數
- 萬用字元
- 佔位符

模式的一些例子包括 `x`、`(a, 3)` 和 `Some(Color::Red)`。在允許使用模式的上下文中，這些組成部分描述了資料的形狀。程式隨後會讓值與模式匹配，以決定它是否具有繼續執行某段特定程式碼所需的資料形狀。

要使用模式，我們會把它與某個值進行比較。如果模式匹配該值，就能在程式碼中使用這個值的各個部分。回憶一下第六章討論 `match` 表示式時用到模式的情形，比如硬幣分類器的例子。如果值符合模式的形狀，就可以使用其中那些被命名的部分；如果不符合，與該模式關聯的程式碼就不會執行。

本章可以視為一份與模式有關內容的參考。我們會介紹哪些位置可以合法使用模式，可反駁（*refutable*）模式與不可反駁（*irrefutable*）模式之間的區別，以及你可能見到的各種模式語法。到本章末尾，你將掌握如何用模式以清晰的方式表達許多概念。
