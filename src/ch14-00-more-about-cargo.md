# 進一步認識 Cargo 和 Crates.io

[ch14-00-more-about-cargo.md](https://github.com/rust-lang/book/blob/43b9ad334aaf7353e5708dba49f84f941b50ec4b/src/ch14-00-more-about-cargo.md)

到目前為止，我們只用過 Cargo 最基礎的功能來構建、執行和測試程式碼，但它還能做得更多。本章會介紹 Cargo 其他一些更高階的功能，並展示如何：

- 使用釋出配置（release profiles）來自定義構建
- 將庫釋出到 [crates.io](https://crates.io)
- 使用工作空間（workspaces）來組織更大的專案
- 從 [crates.io](https://crates.io) 安裝二進位制檔案
- 使用自定義的命令來擴充套件 Cargo

Cargo 能做的事遠不止本章涵蓋的這些；如果想全面瞭解它的所有功能，請檢視[官方文件](https://doc.rust-lang.org/cargo/)。
