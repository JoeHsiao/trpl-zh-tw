# 智慧指標

[ch15-00-smart-pointers.md](https://github.com/rust-lang/book/blob/ecef81cbc6f0c2d1c8a67409329b0641258c04c2/src/ch15-00-smart-pointers.md)

**指標**（*pointer*）是一個包含記憶體地址的變數的通用概念。這個地址會引用，或者說 “指向”（points at）一些其它資料。Rust 中最常見的指標是第四章介紹的**引用**（*reference*）。引用使用 `&` 符號來表示，而且會借用它們指向的值。它們除了引用資料之外沒有任何其他特殊功能，也沒有額外開銷。

另一方面，**智慧指標**（*smart pointers*）是一類資料結構，它們的行為類似指標，但還擁有額外的後設資料和功能。智慧指標的概念並不為 Rust 所獨有：它起源於 C++，在其他語言中也存在。Rust 標準庫中定義了多種不同的智慧指標，它們提供了超出引用所能提供的功能。為了探索這一通用概念，我們會看幾個不同的智慧指標示例，其中包括**引用計數**（*reference counting*）智慧指標型別。這種指標通過跟蹤所有者的數量，讓資料能夠擁有多個所有者；當所有者都不存在時，它還會清理相應的資料。

在 Rust 中，由於所有權和借用的概念，引用和智慧指標之間還有一個額外區別：引用只會借用資料，而智慧指標在很多情況下會**擁有**它們所指向的資料。

智慧指標通常使用結構體實現。智慧指標不同於普通結構體的地方在於它實現了 `Deref` 和 `Drop` trait。`Deref` trait 允許智慧指標結構體例項表現得像引用一樣，這樣就可以編寫既用於引用、又用於智慧指標的程式碼。`Drop` trait 允許我們自定義當智慧指標離開作用域時執行的程式碼。本章會討論這些 trait 以及為什麼它們對智慧指標很重要。

考慮到智慧指標模式是在 Rust 中經常使用的一種通用設計模式，本章不會覆蓋所有現有的智慧指標。很多庫都有自己的智慧指標，而且你甚至也可以編寫自己的智慧指標。這裡會介紹標準庫中最常用的幾種：

- `Box<T>`，用於在堆上分配值
- `Rc<T>`，一個引用計數型別，其資料可以有多個所有者
- `Ref<T>` 和 `RefMut<T>`，它們是通過 `RefCell<T>` 訪問的。而 `RefCell<T>` 是一個在執行時而非編譯時執行借用規則的型別。

另外我們會講到**內部可變性**（*interior mutability*）模式，這種模式允許一個不可變的型別暴露出能夠修改其內部值的 API。我們也會討論**引用迴圈**（*reference cycles*）是怎樣導致記憶體洩漏的，以及如何避免它們。
