# 函式式語言特性：迭代器與閉包

[ch13-00-functional-features.md](https://github.com/rust-lang/book/blob/4b71f17f7daba738a1363862dacb818d9b12fb81/src/ch13-00-functional-features.md)

Rust 的設計從許多現有的語言和技術中汲取靈感，其中一個重要影響就是**函數語言程式設計**（*functional programming*）。以函式式風格程式設計通常會把函式當作值來使用，比如將它們作為引數傳遞、作為其他函式的返回值返回、賦給變數以便稍後執行，等等。

本章不會去爭論函數語言程式設計到底算什麼或不算什麼，而是會討論 Rust 中一些與許多常被稱為函式式語言的特性相似的功能。

更具體地，我們將要涉及：

- **閉包**（*Closures*），一種可以儲存在變數中的類似函式的結構
- **迭代器**（*Iterators*），一種處理一系列元素的方式
- 如何使用閉包和迭代器來改進第十二章的 I/O 專案
- 閉包和迭代器的效能（**劇透警告：** 它們的速度超乎你的想象！）

我們已經介紹過 Rust 中另外一些受函式式風格影響的功能，比如模式匹配和列舉。因為掌握閉包和迭代器是編寫快速、慣用 Rust 程式碼的重要組成部分，所以我們會專門用整整一章來講解它們。
